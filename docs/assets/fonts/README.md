Self-hosted web fonts, all under the SIL Open Font License except Latin Modern.

- Latin Modern Roman (LM-*.woff2): regular, italic, bold and bold italic,
  taken from the latex.css 1.11.0 package. GUST Font License, which permits
  redistribution. Used for blog posts.
- Newsreader (newsreader-*.woff2) and IBM Plex Mono (plex-mono-*.woff2):
  Latin subsets from Fontsource 5.3.0; the *-ext files hold only Latin
  Extended-A (for example the ő in Erdős) and load only when a page uses it.
- glyphs.woff2: the ☜ ☞ ❦ characters cut from Noto Sans Symbols 2.
